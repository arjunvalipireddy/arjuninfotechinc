Our Open Source Tool

Meet RapidFire API

A zero-dependency API load tester built from 20 years of performance engineering experience. Pure Python 3.8+. No npm. No pip. No Docker. Just run it.

Fire your first test in 10 seconds

No setup. No config files. No dependencies to install. Download the script and run it — or grab a pre-built binary for Mac, Windows, or Linux from the releases page.

Built by performance engineers who were tired of needing npm, Docker, or pip environments just to run a quick load test in CI or on a fresh server.

⭐ View on GitHub 📥 Download Binary
terminal
$ python RapidFireAPI_Lite.py \ --url https://api.example.com \ --users 10 --duration 30 ════════════════════════════════════ 🚀 RAPID FIRE API LITE ════════════════════════════════════ Total Requests 1,842 Successful 1,839 RPS 61.4 Avg Latency 161ms P95 289ms P99 401ms ──────────────────────────────────── Result: EXCELLENT ✓
⚡

Zero Dependencies

Pure Python standard library. No pip install, no npm, no Docker. Works in air-gapped servers and CI/CD pipelines with zero setup.

📈

Latency Percentiles

P50, P90, P95, P99 latency breakdowns. Error analysis by type and HTTP status. Automatic pass/fail grading on every run.

🔀

Concurrent Users

Simulate 5 to 200 concurrent virtual users with lightweight Python threads. GET, POST, PUT, PATCH, DELETE with JSON or form body support.

💻

All Platforms

Pre-built binaries for Mac, Windows, and Linux. No Python required to run. Download and fire in 10 seconds.

🛑

Stop Anytime

Press Ctrl+C at any point during the test — the full summary report still prints with all data collected so far.

🆓

Free & Open Source

MIT licensed. Full source on GitHub. Use it, fork it, embed it in your own tools. Community contributions welcome.
